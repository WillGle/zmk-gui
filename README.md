# Curve E Keymap Editor

Web keymap editor for Curve E, based on ZMK Studio (Apache-2.0).
Connect through the existing Studio USB/BLE transports in a supported browser.
Desktop packaging and upstream release automation are not included.

Local fork setup and scope: [FORK.md](FORK.md).

Vercel hosting setup: [FORK.md — Vercel hosting](FORK.md#vercel-hosting).
