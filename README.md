# Curve E Keymap Editor

Web keymap editor based on ZMK Studio (Apache-2.0), primarily used with Curve E.
Other keyboards can also use it when their firmware supports a compatible ZMK
Studio protocol and an available browser USB/BLE transport. Layouts, layers and
bindings come from the connected firmware; the editor is not restricted to Curve E.
Connect through the existing Studio USB/BLE transports in a supported browser.
Desktop packaging and upstream release automation are not included.
